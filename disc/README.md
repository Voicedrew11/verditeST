# disc/

Place your own dump of **Shadow Tower (NTSC-U, `SLUS-00863`)** here.

**Cue/bin:**

```
disc/ShadowTower.cue
disc/ShadowTower.bin
```

A CHD can be extracted with
`chdman extractcd -i "<image>.chd" -o ShadowTower.cue -ob ShadowTower.bin`.

Nothing in this directory is committed except this README (see `.gitignore`), and
no game data is distributed with this project.
